# Game Tournament Country Flags

Open `index.html` with VS Code Live Server.

Files:
- index.html
- style.css
- script.js
- README.txt

Features:
- Country/team flags
- Teams and players
- Individual player scores
- Automatic team totals
- Live match scoring
- Tournament bracket
- Streamer view
- Local browser storage

Note: data is saved in the browser using localStorage. It is not a shared online database.
